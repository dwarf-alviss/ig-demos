# Источники фотографий

Все фото взяты из открытых источников (Openverse: Flickr / rawpixel / WordPress Photo Directory) по лицензиям, допускающим
коммерческое использование, и скачаны локально скриптом `_shared/fetch_photo.py`.
При публичном использовании нужно указывать автора. Для реального клиента заменить на его
собственные снимки букетов.
