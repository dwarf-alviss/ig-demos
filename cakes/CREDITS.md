# Источники фотографий

Все фото взяты из открытых источников (Openverse: Flickr, Wikimedia Commons, StockSnap)
через `_shared/fetch_photo.py` — только лицензии, разрешающие коммерческое использование.
Строка ниже соответствует файлу, который реально лежит в `assets/img/`; при публичном
использовании подпись автора обязательна. Для реального клиента фото заменить на его собственные.

Шрифты: Manrope, Comfortaa, Caveat (все OFL) — локальные копии в `assets/fonts/`,
внешних запросов нет.
Иконки и логотип: собственный набор в `assets/app.js` (`ICONS`) и inline SVG в разметке,
нарисованы для этого сайта. Сторонние иконочные наборы не подключены.
